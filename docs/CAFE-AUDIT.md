## Метод и источники

- [365 Obrador](https://365obrador.com/es/encuentranos/): официальный locator, его публичные результаты с разрешёнными фильтрами 100 результатов / 25 км из центра, северной и западной части агломерации. Повторяющиеся карточки с разными ID объединены. Совпадения улиц, номеров и координат; 13 угловых входов сопоставлены по совпадающей позиции в пределах 25 м. Это географическая сверка, не независимое подтверждение посещением.
- [Buenas Migas](https://www.buenasmigas.com/): все 18 страниц заведений из меню Focacceries. **Gignàs, 25 ошибочно относился к Sandwichez** в исходной карте. Исправлена сеть, старый ID оставлен для избранного.
- [El Fornet](https://elfornet.com/tiendas): 41 магазин и страницы спорных / отсутствовавших адресов. Общий список содержит неточности: например, карточка Llacuna 124 на странице заведения указывает **Llacuna 140–142**, а Pau Claris уточняется как **190**. Страницы заведений имеют приоритет. Для новых точек координаты взяты из опубликованных сетью ссылок на карты. Добавлены Sarrià 1–3, Pallars 193, Rambla 80 (Sabadell), Francesc Moragas 21 (Sant Cugat), Santa Esperança 11 (Granollers).
- [Granier](https://pansgranier.com/donde-estamos/): публичный `shopsArray.json`, используемый официальной картой. 58 точек в исследуемой области. Поле Barcelona в этом источнике означает провинцию, не обязательно город.
- [Sandwichez](https://www.sandwichez.com/locales): 21 адрес; офис отдельно не импортировался. Добавлены Sants 358 и Gràcia 1 (Sabadell). Capità Arenas 3 и Travessera de les Corts 305 отсутствуют в текущем списке. У Capità Arenas есть [вторичный сигнал возможного закрытия](https://es.restaurantguru.com/SandwiChez-Barcelona-6), но его недостаточно для достоверной пометки «закрыто навсегда». Обе записи оставлены неподтверждёнными.
- [Santagloria](https://www.santagloria.com/nuestros-locales): данные маркеров из официального сайта, 57 точек в области сверки. Точки внутри торговых центров с разными адресами/этажами сохранены отдельно. В нескольких карточках координаты расходятся с исходной картой; они отмечены в отчёте.
- [Vivari](https://vivari.es/): HTTPS-сертификат просрочен (`CERT_HAS_EXPIRED`), обход проверки TLS не использовался. Индексируемые официальные страницы рассказывают о сети, но не дают поадресного каталога, позволяющего проверить 123 точки. Их актуальность **не установлена**. Нельзя утверждать, что все они работают или что список новых Vivari полный.

Для координатных каталогов использована область 41.30–41.60 N, 1.90–2.30 E: Барселона и окрестности, а не вся Каталония. Сохранены исходные точки вне прямоугольника; полный официальный список El Fornet включает и Granollers. Поиск новых точек вне этой области по большим сетям не исчерпывающий.

## Сохранённые материалы

- `data/places-audit.csv`: строка для **каждого** итогового места — статус, дата, источник.
- `data/original-places.json`: неизменённые исходные 432 записи.
- `data/official-catalogs.json`: нормализованные официальные записи, ссылки и дата снимка.
- `data/catalog-comparison.json`: сопоставление исходных записей, расхождения координат, отсутствовавшие точки.
- `data/update-summary.json`: изменения адресов, сети и итоговые счётчики.

У статуса `listed` подтверждено наличие адреса на официальном сайте на дату снимка. У `unverified` нет достаточного подтверждения: отсутствие на сайте не доказывает закрытие. Эти точки остаются доступны с явной пометкой. Наличие Wi-Fi, свободных мест и разрешения работать с ноутбуком по каждому заведению не проверено; приложение больше не обещает это автоматически.

При расхождении координат более 150 м сохранена прежняя точка и добавлена заметка; такие маршруты стоит проверить отдельно. По адресам из официального каталога можно найти заведение даже при неточном маркере. Ни часы работы, ни коммерческий статус не выдумываются.

Повторная загрузка My Maps теперь формирует `data/import-candidates.json` и не перезаписывает проверенную базу. Скрипты `fetch-*`, `parse-official-catalogs.mjs`, `refine-catalog-details.mjs`, `compare-catalogs.mjs` документируют эту конкретную сверку; их HTML-парсеры и ручные уточнения необходимо пересмотреть при будущей смене сайтов. Они не являются автоматическим мониторингом закрытий.
