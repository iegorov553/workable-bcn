# Privacy policy hosting

Live URL: https://iegorov553.github.io/workable-bcn-privacy/

Support and privacy contact: workable.bcn@iegorov.com

The owner requested GitHub Pages. A separate public repository contains only the policy:
https://github.com/iegorov553/workable-bcn-privacy

The site is deployed from `main` at `/`, using `index.html`. Its source is also kept in this app at `docs/privacy-policy.html`. It needs no custom domain, backend or separate website framework. No application source was published to that repository.

To update it, edit the local HTML and replace `index.html` in the policy repository. GitHub Pages rebuilds automatically. Keep the update date and data practices accurate. Verify the public URL without authentication after each update. The app uses `PRIVACY_POLICY_URL` in `src/config.ts`.

Google Play requires an active public URL, no geographic access restriction, no PDF and no editing by visitors. The page must identify the app and explain its data practices. Source: https://support.google.com/googleplay/android-developer/answer/10144311#privacy-policy

A published Google Doc would also be an option for a future project, but Workable BCN now uses GitHub Pages. Google documentation: https://support.google.com/docs/answer/183965

This task configured the public support address in the app and policy. It did not create or verify the mailbox itself; its email hosting remains managed by the owner.
