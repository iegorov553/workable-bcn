# Workable BCN

Мобильный справочник кофеен Барселоны и окрестностей на Expo 57. Карта на Leaflet / OpenStreetMap работает во встроенном WebView; Google Maps API-ключ не нужен.

В базе 520 мест семи сетей. На 11 сентября 2026 года 351 адрес найден в официальных каталогах, 169 требуют дальнейшей проверки. Наличие в каталоге не гарантирует часы работы, Wi-Fi или возможность работать с ноутбуком. Подробности и источники: [аудит базы](docs/CAFE-AUDIT.md).

## Встреча на полпути (Meet Halfway)

Режим поиска кофеен, равноудалённых по времени в пути для двух человек (Точка А и Точка Б):
- **Встроенная модель скоростного транспорта**: сеть метро Барселоны (L1–L11), линий FGC (L6–L8) и трамваев (T1–T6) с пересадками и интервалами движения.
- **Пешеходная модель**: расчёт времени ходьбы по манхэттенской сетке Эшампле (коэффициент 1.28) при средней скорости 4.8 км/ч.
- **Справедливый баланс времени**: алгоритм ранжирует заведения с приоритетом минимизации разницы во времени поездки (`|T₁ - T₂|`) и суммарного пути, чтобы ни один из участников не добирался существенно дольше другого.
- **Автономная работа**: все вычисления происходят на устройстве без внешних серверов и сетевых API.
- **Шеринг маршрута**: экспорт и отправка готовой ссылки на навигацию в Google Maps для друга.

## Запуск

Node.js 22.13+ и npm. Для телефона — совместимая версия Expo Go либо APK из EAS.

```sh
npm ci
npm start
```

Отсканируйте QR-код в Expo Go. `npm run web` запускает браузерный preview, `npm run android` — Expo Go на подключённом Android/эмуляторе. Для локальной нативной сборки с настроенным Android SDK: `npx expo run:android`.

Карта использует `react-native-webview` 13.16.1, включённый в Expo Go. Expo DOM больше не используется: HTML, Leaflet, стили и изображения CSS встроены в приложение; по сети загружаются только тайлы OpenStreetMap. Для Expo SDK 57 нужна совместимая версия Expo Go. После изменений остановите предыдущий Metro (`Ctrl+C`), выполните `npm start -- --clear` и откройте проект по текущему QR-коду.

Данные передаются после готовности документа, а не через начальную инъекцию Expo DOM. Веб-версия использует тот же документ внутри iframe. `src/map/map-runtime.js` и `src/map/map.css` — исходники; после их изменения выполните `npm run map:build` и сохраните сгенерированный `src/map/map-html.ts`. Тест проверяет, что этот файл соответствует исходникам. При сбое нативная карта показывает сообщение и кнопку Retry map.

## Проверка

```sh
npm run typecheck
npm test
npm run check:places
npx expo-doctor
npm run export:android
```

Тесты покрывают геолокацию и повторное центрирование карты, тайм-ауты, поиск, избранное и расстояния. JS export не заменяет установку и проверку настоящего Android-билда.

## Сборка и Google Play

```sh
npm run build:apk
npm run build:android
```

Первая команда создаёт APK для тестирования, вторая — production AAB. Требуется вход в Expo/EAS с доступом к существующему проекту. Облачная сборка и загрузка в Play пока не запускались.

Настройки, порядок загрузки и оставшиеся шаги: [Google Play](docs/GOOGLE-PLAY.md). Интерфейс на английском; поддержка: workable.bcn@iegorov.com. [Публичная политика](https://iegorov553.github.io/workable-bcn-privacy/) уже размещена на GitHub Pages и связана с приложением. [Описание магазина](docs/store-listing.md), [исходник политики](docs/privacy-policy.html).

## Данные

`npm run import-map` загружает исходную публичную My Maps в `docs/data/import-candidates.json`. Команда не перезаписывает проверенный каталог приложения. Снимки официальных источников, сопоставление со старой базой и CSV проверки лежат в `docs/data/`. Скрипты аудита отражают структуру сайтов на дату проверки; перед повторным применением нужно проверить парсеры, новые адреса и изменения.

Все 432 исходных ID сохранены для совместимости избранного. Добавлено 88 записей. Неподтверждённые места явно помечены в карточках; автоматически считать их закрытыми нельзя.
